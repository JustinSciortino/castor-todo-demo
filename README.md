# Castor IDE Tutorial: TODO Application

A simple tutorial project designed to walk you through the core features of Castor IDE. Build a basic TODO application while exploring the tools and workflows that make Castor powerful.

## Overview

This project serves as a guided introduction to Castor IDE. By building a straightforward TODO application, you will gain hands-on experience with the platform's key features — from requirements management to code generation, diagram synchronization, and beyond.

## Tech Stack

- **Backend:** NestJS
- **Built with:** Castor IDE

## Tutorial Structure

**Part 1: Guided Demonstration (Requirements 1–3)**  
Follow along through the [tutorial section](https://castor-ide.vercel.app/tutorials) on our website as we use Castor's features to build the core functionality.

**Part 2: Hands-On Practice (Requirements 4–5)**  
Apply what you learned by completing the remaining requirements yourself.
